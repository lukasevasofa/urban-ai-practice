# Подготовка публикации Обнинска

Подготовлен пакет для существующего публичного репозитория `lukasevasofa/urban-ai-practice`, ветка `main`.
Публикация согласована пользователем **без GitHub Pages**. Дашборд открывается как локальный HTML-файл;
приложение — после запуска локального Python-сервера.

## Состав публикации

| Материалы | Расположение |
|---|---|
| Основное описание проекта | `README.md` |
| Выполненный ноутбук, HTML-дашборд, аналитический отчёт | `examples/data/obninsk/` |
| Итоговые кварталы, школы, здания, показатели, граф и матрицы | `examples/data/obninsk/` |
| Окончательные входные данные модели школ | `examples/data/obninsk/practice3/` |
| Приложение, исходный код и локальные файлы Leaflet | `school-placement/obninsk/` |
| Пользовательские А/Б/В, обоснования, полный перебор и CSV | `school-placement/obninsk/results/` |
| Итоговый отчёт эксперимента и сводные таблицы | `school-placement/obninsk/results/final/` |
| Четыре изображения настоящих интерфейсов | `docs/img/obninsk/` |
| Проверка публикуемых материалов | `scripts/check_obninsk_publication.py`, новый workflow проверки |
| Предлагаемые описание About и шесть тегов | `publication/github-settings.json` в папке приложения |

Полный список файлов с размерами и SHA-256 — `files.csv` рядом с этим отчётом.
Он не включает сам себя и производный `checks.json`, чтобы избежать циклических контрольных сумм.
В итоговый коммит также войдут эти два файла.

## Исключения

`.gitignore` исключает `.venv`, кэш, временные тестовые сохранения, системные файлы, скачанные XML OSM,
исходную большую JSON-выгрузку для нарезки, сохранённые страницы заданий, полный архив `population_initial/`,
промежуточные копии ноутбуков и повторно рассчитанные проверочные JSON из `results/final/validation/`.
Они остаются на компьютере. Готовый дашборд и приложение используют сохранённые результаты без этих выгрузок.
Полный повтор исторического ноутбука потребует исключённых локальных источников; сохранённый выполненный
ноутбук доступен для просмотра. Это ограничение прямо описано в главном README.

Код тестов публикуется, технические тестовые сценарии и временные сохранения — нет.
Небольшие исходный/последний расчёты и поквартальные пользовательские JSON сохранены, поскольку используются
приложением и проверкой контрольных сумм эксперимента.

- 20 Python-тестов прошли: один тест пакета и 19 проверок приложения. HTTP-тесту требовалось разрешение
  на временный сервер `127.0.0.1`; после разрешения все проверки успешны. Сценарии тестов изолированы.
- Существующая проверка структуры и генерации дашборда Кореновска выполнена на отдельной копии
  предполагаемого коммита внутри проекта; оба ноутбука Кореновска в ней взяты из `HEAD`.
  Проверка синтаксиса, 403 кварталов сохранённого исследования и генерации HTML прошла.
- Существующие workflow `Tests`, `Dashboard` и ручная проверка пакета сохранены без отключения.
  Их последние опубликованные `Tests` и `Dashboard` успешны на коммите `f835f4f`.
  YAML четырёх публикуемых workflow разобран; удалённый запуск новых workflow возможен только после публикации.
- Контрольные суммы исходных данных `practice3/`, пользовательских сценариев, полного перебора и итогов
  совпадают с протоколом эксперимента. Население 133 000, исходный дефицит 6 812; А/Б/В — по 6 212.
- Секреты и абсолютные личные пути в публикуемых текстовых материалах не обнаружены.
  В предупреждениях выполненного ноутбука удалены 89 локальных префиксов пути: код и числовые результаты
  не изменены. Из XML-отчётов тестов удалено имя компьютера.
- Изображения не содержат адресной строки браузера или личных окон. Сохранена атрибуция OSM на картах.
- Нет файлов >=100 MiB; крупнейший — `walk_graph.graphml`, 15 783 707 байт (15,05 MiB).
  Ограничения проверены по документации GitHub: https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github.

Протоколы: `checks.json`, `python-tests.xml`, `browser-view-checks.json` рядом с этим отчётом.
Страницы статистики администрации, муниципального каталога и лицензирования OSM доступны;
страница отношения OSM не прочиталась через инструмент веб-проверки. Ссылка сохранена без подмены.

## Сохранность Кореновска

В рабочей папке до подготовки публикации уже были изменённый `examples/korenovsk_research.ipynb`
и отсутствующий `examples/korenovsk_geometry_diagnostics.ipynb`. Агент не исправляет и не восстанавливает их.
Оба изменения исключаются из коммита: опубликованная версия исследования остаётся без изменений.
Для коммита будут перечислены только пути Обнинска, README, `.gitignore`, изображения и новые проверки.

## Публикация без GitHub Pages

Пользователь разрешил обычный коммит и push в существующий репозиторий и отказался от GitHub Pages.
Workflow Pages исключён из публикации и сохранён только в игнорируемой локальной папке `runtime/`.
Настройки Pages не меняются. About и тематические теги обновляются согласно согласованному описанию.

Ссылка на дашборд в README ведёт на `examples/data/obninsk/dashboard.html`: файл нужно скачать кнопкой
**Download raw file** на GitHub и открыть в браузере либо открыть из локальной копии проекта.
Приложение доступно только локально: `http://127.0.0.1:8765/`, после команды
`.venv/bin/python school-placement/obninsk/app.py` из корня проекта.

Опубликованные результаты не пересчитываются; изменения Кореновска не включаются в коммит.
